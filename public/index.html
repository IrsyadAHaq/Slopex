Tentang SLOPEX

Smart Landslide Prevention & Geo-Monitoring System

SLOPEX adalah sistem pemantauan lereng berbasis IoT yang menggunakan sensor kelembapan tanah, akselerometer, dan analisis Self-Potential (SP) untuk mendeteksi risiko longsor secara real-time.

Panduan Penggunaan SLOPEX

Akun Anda: Viewer

1

Dashboard — Pantau Kondisi Lereng

Halaman utama menampilkan 5 kartu ringkasan sensor (Risk Score, Soil Dangkal & Dalam, Magnitude, 24 Jam Stats), grafik tren sensor utama, dan snapshot sensor secara real-time. Semua data diperbarui otomatis setiap 2 detik dari Perangkat.

2

Monitoring SP — Grafik Detail

Halaman ini menampilkan grafik kemiringan (Magnitude) dan kelembapan tanah dalam chart terpisah. Di sisi kanan, Anda bisa melihat nilai sensor live dengan bar animasi dan status perangkat (baterai, koneksi, uptime).

3

Peta Lokasi — GPS Tracking

Menampilkan posisi Perangkat pada peta OpenStreetMap secara real-time. Info latitude, longitude, status perangkat, and risk score ditampilkan di bawah peta.

4

AI Analisis — Tanya AI

Fitur chat AI yang menggunakan data sensor real-time untuk memberikan analisis risiko longsor, rekomendasi drainase, dan prediksi. Gunakan tombol pertanyaan cepat atau ketik pertanyaan sendiri terkait geofisika, sensor, dan kondisi lereng.

5

Notifikasi — Alert Otomatis

Klik ikon lonceng di header untuk melihat alert. Saat sensor mendeteksi kondisi WASPADA/BAHAYA, panel notifikasi akan terbuka otomatis. Badge merah menunjukkan jumlah notifikasi belum dibaca.

Fitur Khusus Admin

Kontrol Drainase

Anda dapat membuka/menutup katup drainase secara manual maupun otomatis (saat Risk Score ≥ 75%). Riwayat setiap aksi drainase dicatat beserta siapa yang mengoperasikan.

Perangkat

Lihat detail hardware: Device ID, API Key, endpoint POST, kapabilitas sensor, dan kesehatan baterai (tegangan, arus, suhu MCU). Gunakan halaman ini untuk memastikan alat masih berfungsi dengan baik.

Pengaturan

Kelola profil, ubah nama tampilan, lihat institusi, dan konfigurasi sistem. Hanya admin yang bisa mengakses manajemen perangkat dan pengaturan threshold.

Fitur Khusus Operator

Kontrol Drainase

Sebagai Operator, Anda bisa membuka/menutup katup drainase secara manual. Pastikan untuk memantau Risk Score sebelum melakukan aksi, dan berikan alasan yang jelas pada setiap operasi.

Laporan & Data

Akses 30 pembacaan terakhir dari tabel riwayat sensor dan export data ke format JSON untuk keperluan laporan. Gunakan tombol refresh untuk memperbarui data.

Fitur Khusus Viewer

Akses Read-Only

Sebagai Viewer, Anda bisa melihat semua data sensor, grafik, peta, dan AI Analisis. Namun Anda tidak dapat mengontrol drainase atau mengakses pengaturan perangkat. Hubungi Admin jika memerlukan akses lebih.

Laporan & Export

Anda tetap bisa melihat Laporan & Data dan meng-export data sensor ke format JSON untuk keperluan analisis atau dokumentasi.
